# Divya Darshan — Task 3

A responsive local-business/startup website created for the internship Task 3:
"Local Business Website & Live Pitch Project".

## Project idea
Divya Darshan is a temple-tourism platform concept that brings transport, stays,
food, local guides, temple information and nearby sightseeing into one place.

## Technologies
- HTML5
- CSS3
- JavaScript

## How to run
1. Download or clone the repository.
2. Open `index.html` in a browser.
3. No backend is required for this demo.

## Pitch
The website demonstrates how Divya Darshan can help pilgrims plan a temple trip
and help local service providers reach visitors.
